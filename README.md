# JRender Engine

Welcome to the **JRender Engine 1.0** documentation.

JRender is a Java/LWJGL engine for building real-time 3D scenes, responsive 2D interfaces, post-processing effects, persistent settings, and resource-backed audio. This site is organized in three layers:

- **Welcome and guides** explain how to install the engine and build common features.
- **Theory** explains the engine’s lifecycle, coordinate spaces, rendering flow, and ownership model.
- **API reference** documents every public class, constructor, and function.
